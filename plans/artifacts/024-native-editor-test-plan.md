# Native editor component parity test plan

Generated by `/plan-eng-review` on 2026-09-08.

Branch: `codex/ios-chat-first`

## Affected surfaces

- Native project editor: preview, timeline, tool dock, contextual inspectors, save/reload, and conflict recovery.
- Native account-free UI fixture launched with `-ui-testing-editor`.
- Web plan-item editor ruler, scrub bounds, and rendered/virtual duration display.

## Key interactions to verify

- Select clips, text, caption cues, music, SFX, overlays, visual blocks, motion scenes, camera effects, and carousel moments from the timeline.
- Select active preview objects and cycle overlapping objects with repeated taps.
- Confirm selection seeks to object start without autoplay and routes to the matching inspector.
- Move bars by their body; trim supported bars with separate 44-point edge controls.
- Edit through inspectors, undo, redo, save, reload, and preserve object identity and values.
- Exercise explicit music/carousel removal and empty-section replacement.
- Resolve a baseline conflict without discarding local edits or selection.
- Verify capability-disabled objects remain visible/selectable and name the disabled reason.

## Edge cases

- Half-open visibility at start/end boundaries, zero/negative/invalid durations, overlapping z-order, duplicate/missing IDs, and unknown enum values.
- 43 source assets, 71 timeline slots including 0.1-second microcuts, 40 captions, and overlapping P2/P3 objects.
- Omitted versus empty versus explicit-null commit fields.
- Unknown root/section/item fields and opaque records survive no-op and one-lane saves.
- Duplicate Save, cancellation, offline, HTTP 401/409/412/500, malformed response, render-enqueue failure, and capability changes after load.
- Dynamic Type accessibility sizes, VoiceOver traversal/actions/selected traits, Reduce Motion, RTL layout, and minimum 44×44 targets.
- Web rendered duration differs from virtual edit duration.

## Critical paths

- Load full-lane server document → decode losslessly → select/edit one item → commit changed section only → refetch → preserve every untouched lane.
- Timeline tap → seek/select → preview outline → inspector edit → one undo entry → redo → save.
- Preview tap at overlap → topmost selection → repeated deterministic cycling → empty tap clears.
- Save with stale generation → conflict UI → retain local state → explicit reload/rebase → stable selection where possible.
- Open and operate the 71-slot stress fixture within performance budgets without AVPlayer composition rebuilds on clock ticks.
- Ruler, playhead, scrub bounds, and transport communicate one coherent duration model.
