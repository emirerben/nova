# Kria Agent Platform Test Plan

Generated by autoplan engineering review on 2026-09-06. Source: `plans/023-kria-agent-platform.md`.

## Affected Pages and Routes

- `/plan` — create or resume a runtime-v2 project, send turns, inspect/undo draft work, approve/cancel renders, keep chatting during render, review results, and recover.
- `/plan/items/{id}?embedded=1` — hydrate the same authoritative draft, Save through revision CAS, and return to the same conversation.
- `POST /creation-threads/{id}/turns` — replay-safe turn acceptance and 202 lifecycle.
- `POST /creation-threads/{id}/turns/{turn_id}/cancel` — planning/queued/approval cancellation.
- `POST /creation-threads/{id}/approvals/{approval_id}/{approve|deny}` — exact-state consent and atomic edit/Job acceptance.
- `GET /creation-threads/{id}?after_sequence=N` — cursor deltas, compact projection, coalesced lifecycle identity.
- `GET|PUT /creation-threads/{id}/draft` — authoritative snapshot, ETag/revision CAS, editor compatibility.
- `/admin/jobs/{id}` — reconstruct turn, policy, approval, receipt, Job, evidence, observation, and queued successor.

## Critical End-to-End Journeys

- Raw montage footage → natural-language goal → useful editorial response/draft → render approval → one Job/generation → playable evidence review → accepted result.
- Talking-head clip → caption and speech-cut edits → inspect/Undo → approved rerender → exact refreshed result.
- Narrated/guided/mixed-media inputs → format-specific required operation subset → recoverable unsupported request without generic limit text.
- Render in progress → status question → one queued revision intent → replace/cancel → fresh replan after success and after failure.
- Refresh and second device → same transcript/draft/approval; stale writer gets refresh/replan and no lost work.
- Legacy runtime-v1 project → unchanged creation/copilot/render behavior with v2 flags on and off.
- Feature rollback → no new turn claims, accepted Jobs settle, queued turns/approvals cancel, committed results remain readable.

## Concurrency and Crash Boundaries

- Same turn submitted twice and same key reused with a different body.
- Two turn tasks race for one lease; heartbeat expires during model inference; stale epoch attempts to write.
- Approval double-tap, approval after draft/job/generation drift, approve versus deny, approve versus cancel.
- Process death after user event, after task publish, during inference, after draft receipt, after approval consume/edit commit, before render publish, after broker acceptance, after worker terminal write, and before observation.
- Duplicate/out-of-order worker callback and older-generation completion after a newer generation becomes active.
- Assert one source event, one active/queued turn, one draft head per revision, one execution identity, one Job generation per approval, and one observed completion.

## Error and Boundary Cases

- No footage, insufficient footage, missing voiceover, unsupported/disabled format or tool, stale/missing evidence, expired playback URL, and malformed model schema.
- Atomic bundle with one invalid op; later dependency group failure after an earlier group succeeds; observer failure after tool success.
- Draft empty state, invalid schema, >2 MiB payload, maximum operations, maximum caption/overlay rows, head-only Undo after intervening write, and pruned history.
- Broker unavailable/ambiguous, agent-control unavailable, render worker death, partial variant success, review unavailable, cancel losing to completion.
- Cross-tenant thread/item/job/draft/approval IDs and prompt injection through filename, transcript, OCR, or metadata.
- Cursor at start/end/gap, duplicate delta, old-generation event, >100 legacy mirrored events, 10,000-event project, and query-count invariance.
- Offline composer, reconnect, mobile Chat/Editor tabs, live-edge scroll versus New update, keyboard order, screen-reader announcements, 44px targets, 200% zoom, and reduced motion.

## Agent Evals

- Add runtime-v2 structural fixtures for both envelopes, legal turn values, evidence references, bounded tools/dependencies, prospective versus completed language, and deterministic fallback.
- Add ≥30 labeled cases per canonical format token, including all mandatory safety/recovery scenarios and an independent pre-capability request corpus.
- Add injection and failure corpora; keep execution completion and recovery specificity as separate metrics.
- Run structural replay in CI and live judged evaluation against consented Nermin lifestyle, matcha-business, and travel fixtures before cohort release.
- Any prompt/schema change bumps the v2 `AgentSpec.prompt_version`; compare against current Nova and frozen labels.

## Performance and Operational Gates

- Turn useful-response p95 <30 seconds; agent-control queue wait p95 ≤2 seconds; lease-loss rate <0.1% in shadow; report p50/p95/p99 components.
- First playable cut p50 <5 minutes and p90 <10 minutes for the defined media class; include nominal/elevated render queues.
- Draft fetch is separate and ETag-aware; thread delta query count is constant with transcript length; model context never contains full history/editor JSON.
- Alerts and admin trace verified for expired lease, accepted-undispatched work, old `outcome_unknown`, duplicate generation, observer lag, queue starvation, and maintenance lateness.

## Developer-Experience Acceptance

- From a prepared worktree, the first credential-free replay completes in under 60 seconds and setup plus success takes no more than 15 minutes.
- The replay emits matching readable and JSON traces covering snapshot, plan, policy, tool, receipt, and semantic observation without network, provider, storage, broker, or renderer dependencies.
- A new read-only tool requires one executor, one registry entry, and one fixture; a CI test proves no prompt/API/UI switch is needed.
- Runtime-v2 OpenAPI, TypeScript types, tool reference, and registry schema stay in sync under one drift gate.
- Starting with only a thread or turn ID, an engineer reaches the exact approval/execution/Job/generation/task and a safe recovery action within 10 minutes.
