# KRI-524 root cause and corrective design

The incidents exposed several contract failures across extraction, routing, editing and verification. They do not establish universal model reliability.

1. **Title duration versus footage preservation.** A keyword-based verifier treated “whole video” as a source-footage constraint even for a title-scoped timing requirement. The verifier now respects the requirement's scope and requires actual title timing evidence.
2. **Structure versus appearance.** The recovered word-animation turn applied only a whole-title fade. Existing per-bar operations and incomplete capability descriptions did not adequately express a conserved sequence of independently timed chunks. The new atomic `replace_text_sequence` accepts arbitrary words, phrases or clauses, preserves wording and style, and gives each chunk its own non-overlapping window. The prompt explains the operation schema and separates text structure, timing and appearance; no request-phrase branch was added.
3. **Composition across edits.** A vertical-only coordinate patch reset the horizontal coordinate. The parser now preserves unspecified axes. Title selectors now recognize explicit title roles, and sequence children retain their common identity through the existing `source_params` metadata. The save regression reads the normalized saved variant, rebuilds the snapshot, and changes every child's font without changing wording or timing. Server operation limits now match the compiler's 16-operation bound.
4. **Brief extraction bypassed full intent binding.** A speculative brief-enabled fast path accepted a subset before typed extraction, so compound requirements could be routed incompletely. The fast path is removed. `MainCreator` now replans through the full existing binding/clip-intent pipeline; the planner passes the whole effective brief to the editor. Failures stop mutation and preserve the valid request, distinguishing `editor_planning_failed` from extraction failure.
5. **Capabilities were not derived from the compiler.** Legacy playback-speed handling could produce a false proposal. `timeline_patch_capabilities` now derives from compiler flags, and unsupported operations are rejected with their structured unmet reason. Canonical caption properties project into the next turn; plural intro/title-group selection updates both stacked titles while excluding unrelated locations.
6. **Valid model output rejected after the retry boundary.** Production traces show the brief extractor succeeded for the correction; its exact output is redacted. A later deterministic planning/brief-application failure was collapsed into `request_extraction_failed`. Contextual ledger checks now run inside the extractor's bounded schema-retry loop, allowing invalid versions, targets or conflicting updates to be repaired before being reported as a successful extraction. Persist-time version checks remain unchanged.
7. **Reporting mutation as completion.** Merely changing text previously marked a style request met. That shortcut is removed: missing field-level evidence stays unverified. Unsupported responses now surface their structured limitation instead of hiding it behind generic redirect copy.

Live probes deliberately retained their initial failures. The expanded probes covered 28 broad editor cases, 18 creation cases across nine formats and phone/cloud destinations, and 18 chain cases. The final chain covered nine distinct cases; seven changed supported cases passed compile/save, one supported title-only case passed with an honest limitation, and no-op passed. D's missing-base-video fixture correctly returned 422 and E's complete fixture rerun passed. A separate Gemini Pro brief extraction → routing → Flash editing → compilation/save-validation probe passed. These are bounded component and fixture checks, not a full HTTP, database/object-existence, phone-export or audible-continuity test.

Offline evidence includes real compiler/save normalization and production Skia overlay pixels. The final prompt is v74. Extracting the effective brief before proposing an edit adds serial model-call latency; observed full chains were roughly 10–20 seconds, with no SLA claim. The 252-library matrix remains unexecuted, the exact “graded title” conversation remains unrecovered, and the renderer plus approval/authorization boundaries are unchanged. Related gaps remain tracked in KRI-350 (canceled speed ramps), KRI-449 (audio-level renderer), KRI-527 (speech excerpt with pinned text), KRI-519, KRI-514, KRI-523 and KRI-522; this work does not revive, close or claim those separate gaps fixed.
