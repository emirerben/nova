# KRI-524 root cause and corrective design

The incidents exposed several independent contract failures. They were not evidence that Gemini cannot understand the request.

1. **Title duration versus footage preservation.** A keyword-based verifier treated “whole video” as a source-footage constraint even for a title-scoped timing requirement. The verifier now respects the requirement's scope and requires actual title timing evidence.
2. **Structure versus appearance.** The recovered word-animation turn applied only a whole-title fade. Existing per-bar operations and incomplete capability descriptions did not adequately express a conserved sequence of independently timed chunks. The new atomic `replace_text_sequence` accepts arbitrary words, phrases or clauses, preserves wording and style, and gives each chunk its own non-overlapping window. The prompt explains the operation schema and separates text structure, timing and appearance; no request-phrase branch was added.
3. **Composition across edits.** A vertical-only coordinate patch reset the horizontal coordinate. The parser now preserves unspecified axes. Title selectors now recognize explicit title roles, and sequence children retain their common identity through the existing `source_params` metadata. The save regression reads the normalized saved variant, rebuilds the snapshot, and changes every child's font without changing wording or timing. Server operation limits now match the compiler's 16-operation bound.
4. **Valid model output rejected after the retry boundary.** Production traces show the brief extractor succeeded for the correction; its exact output is redacted. A later deterministic planning/brief-application failure was collapsed into `request_extraction_failed`. The precise historical rejection is unknown. Contextual ledger checks now run inside the extractor's existing bounded schema-retry loop, allowing invalid versions, targets or conflicting updates to be repaired before being reported as a successful extraction. Persist-time version checks remain unchanged.
5. **Reporting mutation as completion.** Merely changing text previously marked a style request met. That shortcut is removed: missing field-level evidence stays unverified. Unsupported responses now surface their structured limitation instead of hiding it behind generic redirect copy.

Live probes deliberately retained their initial failures. Final canonical probes exercised unseen chunks, a correction, whole-title negative instructions, a compound color/animation request, an already-satisfied request, current-cut preservation and unsupported speech replacement. A separate Gemini Pro extraction → routing → Flash editing → compilation/save-validation probe also passed. These are component-level live checks, not a full HTTP or phone-export test.

Offline evidence includes real compiler/save normalization and production Skia overlay pixels. It does not establish universal model reliability, full original-video export, audible continuity, or recovery of the original “graded title” conversation. The renderer and approval/authorization boundaries are unchanged.
