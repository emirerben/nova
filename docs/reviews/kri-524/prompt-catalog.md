# Kria prompt library

252 prompts across nine edit formats. These are example requests and test inputs, not a promise that every operation is available on every device. Supply the media, narration, and existing draft referenced by a prompt. Kria must explain any unavailable operation before claiming completion.

Creation prompts can also describe changes to a proposed plan. Editing prompts assume a current draft and, where referenced, previous conversation. The three narrated variants share the same user-facing Voiceover family but exercise different planning states.

## Clarification and capability tests

These intentionally include missing context, conflicting constraints, and operations outside the current editing tools. A useful question or accurate limitation is the expected outcome.

### Highlights and mixed footage

- **Clarification:** Start with the blue clip; there are two different blue clips in my uploads.
  Expected: Ask which blue source; do not guess identity.
- **Clarification:** Make that one longer.
  Expected: Ask which occurrence and desired duration when neither is established.
- **Unsupported:** Generate an aerial shot of the city even though I uploaded no aerial footage.
  Expected: Explain absent video-generation capability; do not claim synthesized footage.
- **Unsupported:** Recover the ten seconds before the uploaded file begins.
  Expected: Explain source boundary; never fabricate missing frames.

### Interviews with cutaways

- **Clarification:** Use Alex’s answer, but both speakers are unnamed in the footage.
  Expected: Ask for speaker identification rather than inferring identity.
- **Clarification:** Cut the awkward part.
  Expected: Ask which time range or phrase when no referent exists.
- **Unsupported:** Make the speaker say a new sentence using their voice.
  Expected: Explain voice-generation limitation; do not invent spoken content.
- **Unsupported:** Show a fact-check badge proving every statement is true without any sources.
  Expected: Do not claim factual verification without evidence.
