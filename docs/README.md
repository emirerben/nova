# Nova navigation map

Use this as an entry-point map, not as a second architecture document. Start at
the symptom, open the named symbol, then run the focused tests in the same row.
For working-tree freshness, branch handoff, and ownership checks, read the
[agent navigation runbook](runbooks/agent-navigation.md).

Source defaults are the code contract. A dated production profile may override
them through Fly/Vercel flags; verify the active settings before diagnosing a
rollout. Historical review notes explain why a guard exists, but do not replace
the current symbol or test.

## Focused discovery

From the selected worktree, locate a symbol or test before opening a broad tree:

```bash
rg -n 'struct EditorDraft|func save' src/apps/ios/Kria/Core/Models.swift src/apps/ios/Kria/Features/NativeEditorSession.swift
rg --files src/apps/api/tests/kria | rg 'runtime|stale_head|editor_state'
rg -n 'def resolve_editor_base|def build_editor_snapshot' src/apps/api/app/services/kria_editor_ops.py
```

Run backend checks through `scripts/check-api.sh`; usage and runtime-profile
interpretation are in the [agent navigation runbook](runbooks/agent-navigation.md).
