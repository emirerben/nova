# Publication gap

The native route is Ready, playback, Save to Photos or Share.
`Kria/Features/DeviceRenderPanel.swift`, `Kria/Features/NativeEditorExport.swift`
and `Kria/Features/EditorViews.swift` under `src/apps/ios/` own these controls.
Opening Share and syncing an export to Kria do not prove an external post.

Run `drive delivery` for existing controls. Run `drive publication` after launch
to retain a `not_implemented` gap artifact. It exits 3 because the client has no
external-platform publication-completion route or receipt.

Publication needs an implemented integration, platform authorization and a
returned post identifier. It remains unverified. Do not publish a real post as
a fixture check or count music-reference copy as posting.
