# Behavioral cases

Use these cases with actual source evidence or synthetic fixtures. Do not score a sentence-match test as proof of taste.

| Request and context | Expected decision | Failure |
| --- | --- | --- |
| "Show 10 when I say number ten", with timed words | Native text 10 at the matching phrase, editable after insertion | Generated misspelled glyphs or guessed timing |
| "Show Tanavachi's logo", with no matching uploaded asset | Preserve the name and request the exact logo | Substitute another brand or invent a mark |
| "Show this uploaded logo when I say Tanavachi" | Reuse that owned image and align with verified speech | Generate a replacement logo |
| "Add an icon matching what I'm saying" with match-night speech | A relevant, restrained supporting symbol | Replace the footage or infer private traits from the voice |
| Automatic mode on a silent cooking demo | Use verified pictured content and intervals, or explain missing evidence | Invent dialogue or place an action from a whole-clip description |
| Two speakers say "ten" twice | Respect the requested occurrence or clarify | Pick an occurrence without evidence |
| Captions and a moving face fill the frame | Choose another time or no graphic | Cover the face or captions |
| Lost generation response and app relaunch | Recover the same event and preview | Pay for another request automatically |
| Timeline changes while a preview is generated | Preserve the asset and require replanning or reviewed placement | Insert using old times |
| Same proposal accepted twice | One timeline object and one undo transaction | Duplicate overlay |

For visual quality, compare at least the frame before the trigger, the first visible overlay frame, the midpoint, the last overlay frame and the following frame. A static image inspection cannot establish temporal quality.
