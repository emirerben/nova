# Licensed SFX placement rubric

Score whether each placement uses an effect from the supplied catalog and a
supplied word, pause, or visual-moment timing mark. Prefer a small number of
clear, funny moments over generic or speculative sound design. The requested
effect must be used consistently, with no more than six placements, at least
1.5 seconds apart, and at least 0.5 seconds before the end of the edit.

Do not reward invented timestamps, effect names, or descriptions unsupported by
the supplied evidence. An empty placement list is acceptable only when the
input contains no grounded comedic moment; when moments are supplied, select
the strongest grounded moments.
