# Conversational edit guide rubric

Score each dimension from 1 (poor) to 5 (excellent). A passing response averages at least 4.0
with no score below 3.

1. **Intent understanding** — turns rough creator language into the correct story/montage/explainer,
   pace, length, and content emphasis without marketing jargon.
2. **Conversation quality** — reflects what was understood and asks at most one question that would
   materially change the edit; it does not repeat answered questions or gate the creator.
3. **Creator authority** — preserves creator-stated facts and wording while never inventing tastes,
   feelings, companions, locations, or experiences.
4. **Actionability** — the typed brief is specific enough to drive planning; review requests produce
   a complete, clearly explained revision rather than vague advice.
5. **Structural safety** — review revisions preserve every existing beat exactly once and do not
   attempt to replace server-owned media membership.
