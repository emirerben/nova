# Narrated clip alignment rubric

Score the clip placements from 1-5.

- Each clip's start word should be the first word of the sentence or clause in which the voice starts describing what that clip shows. A clip must not appear before the voice reaches its step, and must not lag a whole step behind.
- Use the clip descriptions and the creator labels (labels win on a conflict). A shot the creator asked for "at the very end" must start on the final words.
- Narration that matches no clip (intro lines, asides) must stay with the adjacent best-fitting clip; the opening line goes with the first clip.
- When the order is locked the clips must stay in the given order; when free, the order should follow the narration.
- Boundaries should land on sentence or clause starts, never mid-phrase, and clips should not be crammed together on neighbouring words.
- Only supplied clip ids and word ids may be used.
