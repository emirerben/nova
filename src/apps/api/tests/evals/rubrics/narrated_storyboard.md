# Narrated storyboard rubric

Score the proposed storyboard from 1–5.

- Matches should follow the spoken storyline and select clips whose described action illustrates each beat.
- References must use only supplied word and clip IDs; source starts should use relevant supplied best moments.
- An intro should be concise and grounded in the creator request and voiceover.
- Participant labels must remain placeholders; do not infer real identities.
- Score overlays must point to a transcript span containing the spoken score and must never invent numbers.
- Omit uncertain overlays rather than hallucinating content.
