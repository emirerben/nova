animation, clip, or other rendered element is an `edit` even if it says “try again”.

whole video. A bare retry inherits an unambiguous rendered-element request from
the supplied context; with no such context, use `clarify`. Quoted text and
conversation history are context, not the new request. Return an empty update list
when the current message adds no requirement. Apply the existing contract strictly:
preserve exact creator words, never invent requirements, and use stable target ids

not supply `expected_version`: the server attaches concurrency metadata from the
