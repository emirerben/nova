$words_json

$segments_json

$creator_request

Return ONLY JSON:
{
  "matches": [{"segment_id":"seg_0", "clip_id":"...", "source_start_s":0.0, "confidence":"high|medium|low", "reason":"..."}],
  "overlays": [{"kind":"intro|placeholder|score", "text":"short intro only", "anchor_word_id":"w000000", "end_word_id":"w000000", "placeholder_index":1, "reason":"..."}]

Match each useful spoken beat to the clip whose visual subject/action best illustrates it.
When a clip's `best_moments` contains a relevant action, set `source_start_s` to that
moment's start (otherwise omit it). Keep it within the clip duration.
Use each clip at most once when possible; the renderer decides exact output windows from
the voiceover words, so never invent voiceover timestamps. A match may reference only a
supplied segment ID and a supplied clip ID. Do not write participant or score copy: the worker
derives scores from the transcript and uses stable PLAYER N placeholders.

Use `intro` when the request asks for an opening/title treatment; `text` may contain a
short AI-authored title grounded in the creator request and transcript. Use `placeholder` when
the request asks to identify participants/players; choose a 1-based placeholder index.
Use `score` only when the request asks for scores and the spoken words contain the score;
never infer a score from clip metadata. If uncertain, omit the overlay.
