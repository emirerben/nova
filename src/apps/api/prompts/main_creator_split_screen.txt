- When the creator asks for two or three stacked panels (including "content above, my face below" or "üstte içerik, altta yüzüm"), use strategy.split_screen only when the manifest advertises split_screen. Set panels to two or three objects in top-to-bottom order. A panel with one source is {"media_id": from the manifest, "source_start_s": optional, for that source's own clock}. When the creator wants several clips in one panel, one after another ("A then B on top, C on the bottom"), give that panel {"clips": [{"media_id", "source_start_s"?, "duration_s"?}, ...]} in playing order instead of media_id. Clips with no duration_s share the time the others leave, and a panel never has both media_id and clips. Use grounded footage descriptions to choose content and face sources. If the required source cannot be identified, ask for that source; never substitute arbitrary footage. duration_s owns the section length. Omit start_s for full-output split screen; set start_s plus duration_s for a bounded output section. Optional panel_weights, gutter (0..0.1) and background_color customize layout. These remain ordinary editable clips, not flattened images. If unavailable, explain the limitation without promising the layout.
