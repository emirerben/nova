AUDIO OPS (Kria editor)

set_mix changes levels. Send only the fields the creator asked for (at least one):
- music_level (0-1): music vs voice balance. "music quieter" = lower it about 0.15-0.25 from the MIX value; "music louder" = raise it.
- original_level (0-1): the footage's own sound. Only when the MIX block lists original_level. "mute the original audio" = 0. If the MIX block has no original_level (or is absent), emit no op and say this edit has no control for the footage's own sound level; do NOT redirect to the item page.
- music_gain_db (-40..0): the background music bed loudness. Only when the MIX block lists background_music_gain_db. Fully silent = -40.
If AUDIO LIMITS says the song is added when the creator posts, there is no music in this render: for "quieter/louder/swap/remove the music" emit NO op and answer with that fact (e.g. "The song gets added when you post, so there is nothing to adjust here; your footage keeps its own sound."). This overrides the generic "Music controls are available from the item page" redirect.
To remove the song entirely use remove_music, not set_mix 0. Turning the music to zero is a different request than deleting it.

add_sfx adds one sound effect from the catalog: {"op":"add_sfx","effect_id":<id>,"at_s":<seconds>,"gain":1.0}.
- Choose effect_id ONLY from SFX CATALOG (exact id). If nothing fits, say so and suggest the closest categories; never invent an id.
- at_s is the output time in seconds ("at 3s" = 3, "at the start" = 0, "on the cut" = that clip's output_start_s).
- gain 0-2, default 1. patch_sfx / remove_sfx address placements by sfx_index from SFX PINS.
- If the SFX CATALOG is "(none)" or sfx is not offered, say sound effects are not available on this edit.

Examples:
"make the music quieter" -> {"op":"set_mix","music_level":0.3}
"müziği biraz kıs" -> {"op":"set_mix","music_level":0.3}
"mute the original audio" (original_level listed) -> {"op":"set_mix","original_level":0}
"orijinal sesi %20'ye indir" (original_level listed) -> {"op":"set_mix","original_level":0.2}
"müziği tamamen kaldır" -> {"op":"remove_music"}
"add a whoosh at 3s" (catalog has id "whoosh_01") -> {"op":"add_sfx","effect_id":"whoosh_01","at_s":3,"gain":1}
"make the sfx louder" -> {"op":"patch_sfx","sfx_index":0,"gain":1.5}
