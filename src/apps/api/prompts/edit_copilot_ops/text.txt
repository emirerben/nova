TEXT SELECTOR OPS (change many texts in ONE op; prefer these whenever an ask covers more than one text):
selector = {"group":"title"|"labels"|"free"|"all", "contains":"...", "equals":"...", "clip_ids":["<media_id>"], "clip_indexes":[<CLIP SLOTS index; creators count clips from 1, indexes start at 0>], "bar_indexes":[<TEXT BARS index>]}
- Criteria combine with AND; at least one is required ("everything" = {"group":"all"}). labels = per-clip label bars (label_for_clip=...), title = the title bar, free = every other text.
- contains/equals ignore case and Turkish diacritics (İ/ı/ş/ğ/ç/ö/ü), so "arnavutkoy" matches "Arnavutköy Sahili".
- rewrite_text: {"op":"rewrite_text","selector":{...},"text":"exact new wording"} sets every match to that text; or "replace":{"find":"Istanbul","with":"İstanbul"} edits inside each match (only texts containing find change). Exactly one of text/replace. Use it for the creator's own wording. Use label_each_clip ONLY when labels should be regenerated from clip facts.
- patch_text: {"op":"patch_text","selector":{...},"patch":{...}}. patch fields: font_family, size_px (absolute) or size_scale (0.25-4 multiplier, "20% bigger" = 1.2), color, highlight_color, background_color ("#RRGGBB" box behind the text, null removes it), effect, alignment, text_case, letter_spacing, line_spacing, max_width_frac, stroke_width, shadow_enabled, position/x_frac/y_frac/rotation_deg, behind_subject (bool), animation_phases {entrance|exit: none|fade|pop|slide|typewriter, loop: none|pulse|bounce|float, speed 0.25-3} (only the keys you set change). "pop-in"/"animate in" = animation_phases.entrance "pop". Unlisted fields are rejected.
- remove_texts: {"op":"remove_texts","selector":{...}} deletes every match ("delete all labels").
- set_texts_timing: {"op":"set_texts_timing","selector":{...},"start_s":0,"end_s":3} or "shift_s":-0.5 (moves matches, keeps their duration).
- add_text also takes optional style_from ("title"|"labels"|a bar id: copy that bar's look), patch (as above), position (top|middle|bottom|top_left|...), animation_phases, clip_id (<media_id>: makes it that clip's label; style_from defaults to labels). Set style_from:"title" so new text matches the video unless the creator asked for a specific style. "At the end" = start about 2s before TOTAL DURATION.
- A selector that matches nothing becomes a clarification; do not guess ids. Never split a bulk ask into one op per bar.
- When the ask NAMES specific text ("all X labels", "labels that say X", "the X one"), X MUST be in the selector as contains (or equals). Never widen it to the whole group or pick other texts: if no visible text contains X, emit no op and reply that nothing contains X.
