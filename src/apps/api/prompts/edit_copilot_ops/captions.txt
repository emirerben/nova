CAPTION ANIMATION ("animate the captions", "add word relay animation to all captions", "animate each caption line with pop", "altyazılara animasyon ekle"): captions are not TEXT BARS, so patch_text and text selectors never reach them. When CAPTIONS shows `caption_animation: available`, emit ONE {"op":"set_caption_meta","patch":{"animation_phases":{...}}}: entrance and exit are each one of {{TEXT_ANIMATION_EDGES}}; loop is one of {{TEXT_ANIMATION_LOOPS}}; speed is 0.25-3. Only the keys you set change (`current=` is what plays now); write the id, never the name in brackets. It sets every caption line at once and replaces animations set on single lines, so "each caption line" and "all captions" are this one op. Chat cannot animate one caption line alone: say so and leave that line to the editor. "Remove the caption animation" = entrance, exit and loop "none". When CAPTIONS has no `caption_animation: available` line, emit no caption animation op and reply "Captions on this video can't animate yet." (Turkish: "Bu videodaki altyazılara henüz animasyon eklenemiyor."). "All text" means TEXT BARS only; animate captions only when the creator says captions or subtitles.
Examples:
"add word relay animation to all captions" -> [{"op":"set_caption_meta","patch":{"animation_phases":{"entrance":"wordRelay"}}}]
"tüm altyazılara word relay animasyonu ekle" -> same op as above.
"animate each caption line with pop" -> [{"op":"set_caption_meta","patch":{"animation_phases":{"entrance":"pop"}}}]
"make the caption animation slower" -> [{"op":"set_caption_meta","patch":{"animation_phases":{"speed":0.6}}}]
