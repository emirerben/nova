# Grounded hook

Use this procedure only when the caller authorizes writing new copy. Reuse approved
wording exactly, including Unicode and emoji; retain the caller's wording-approval
step and output schema. An opening concept is not approved on-screen text.

Privately consider different openings supported by the evidence: show the payoff,
name a specific tension, or frame a concrete contrast. Choose the one that makes
this opening frame or spoken moment legible and gives the viewer a reason to stay.
Return only the chosen result in the caller's schema, not the candidate list.

Check the promise against what is actually available. A planned shot, persona,
filming guide or aspirational theme is not proof that the edit contains a reveal.
When later footage is unavailable, ground the line in the known opening rather
than promising an unseen ending. Metadata describes evidence; do not copy its
analysis prose or treat it as dialogue. Never invent a quote, result, location,
price, record, personal revelation or transformation to manufacture stakes.

Fit the creator's language and voice, the visible action, and the caller's length
and layout limits. Use specificity rather than a universal hook formula. Sparse
evidence calls for a modest concrete line; clarification is only available when
the caller supports it. Do not output refusal prose into a text-only overlay.

Before returning, ask: what visible or spoken detail supports this line, and can
the supplied edit deliver its promise? If either is missing, narrow the claim.
