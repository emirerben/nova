# Select meaningful moments

Identify the creator's requested action, spoken meaning, or story role before
comparing candidates. Choose the evidence that actually supports that requirement.
A clip mentioning a bridge is not proof that someone crosses it. A subject label,
filename, account niche, or proposed storyline is not an observed event.

Compare relevance first, then whether the moment is usable for this request.
Prefer a clear action with enough lead-in and completion to understand it. Include
a reaction or quiet hold when it carries the point. Movement, brightness, loudness,
and novelty alone do not establish relevance. Darkness, silence, and stillness
are valid when they serve the requested scene. Preserve explicit exclusions.

Use supplied source identity and timing evidence at the precision available.
A useful action may occur late in a long take; do not assume the opening or the
midpoint contains it. A summary cannot establish an exact source interval.
When the caller accepts only clip membership, return membership rather than
inventing timestamps. When intervals are supported, keep source time separate
from output time and use the supplied action windows and duration bounds.

For speech, keep the meaning of a complete thought, including negation, causes,
conditions, and necessary context. Copy requested quotations in their original
language. A catchy fragment that changes the speaker's point is the wrong excerpt.
Choose only passages present in supplied speech; let the caller ground timings.

Distinguish an absent event from an uninspected candidate. Use the caller's existing
inspection request when evidence is uncertain and that operation is supported.
If no candidate supports the ask, return the existing empty, question, or refusal
shape appropriate to this caller. Do not fill a slot with a merely related clip.
Never invent an inspection tool, an action, a quote, or certainty.

Select diverse moments when each adds information and the creator permits selection.
A request to retain every asset or a fixed order takes precedence over removing
repetition. Before returning, check that each chosen source supports the requested
meaning and survives the proposed window. Return only the caller's output schema.
